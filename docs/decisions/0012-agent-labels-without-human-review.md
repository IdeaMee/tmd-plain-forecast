# 0012 ใช้ป้ายของผู้ช่วยเป็นป้ายสุดท้าย ไม่มีคนติดซ้ำ

Status: accepted (2026-11-17) · แทนส่วน "ผู้ใช้ติดซ้ำ 20%" ของ [0007](0007-labeling-and-evaluation.md)

Context: Phase 2.2 ผู้ช่วยติดป้ายครบ 292 หน่วยและทำไฟล์สุ่ม 59 แถวให้ผู้ใช้ติดซ้ำแบบไม่เห็นป้าย (Phase 2.3) ผู้ใช้ตัดสินใจไม่ติดซ้ำ และให้ใช้ป้ายของผู้ช่วยต่อเลย

Decision
- `final_label` = `suggested_label` ของผู้ช่วยทุกแถว, `reviewer` = `agent-only` · ปิดชุดป้ายด้วย `data/labeled/FROZEN.md` (`scripts/freeze_labels.py`)
- ข้าม Phase 2.3 · `data/labeled/blind_sample.csv` เก็บไว้แต่ไม่ได้ใช้
- รายงานเขียนตามจริงว่า "ป้ายติดโดยโมเดลภาษา (Claude) ไม่ได้ผ่านคนตรวจ" แทน "ตรวจโดยคน 20%"

Consequences
- ไม่มีอัตราตรงกันระหว่างคนกับผู้ช่วย ความน่าเชื่อถือของป้ายจึงไม่ได้วัด ความเข้าใจผิดของผู้ช่วยอาจซ้ำทุกแถว
- accuracy ใน Phase 2.4 คือ "โมเดลทำซ้ำป้ายของผู้ช่วยได้แค่ไหน" ไม่ใช่เทียบกับป้ายที่คนยืนยัน ต้องเขียนข้อจำกัดนี้ในรายงานผล
- ถ้าภายหลังผู้ใช้ติด `blind_sample.csv` ก็คำนวณอัตราตรงกันเพิ่มได้โดยไม่ต้องแก้ป้ายที่ปิดแล้ว (เป็นการรายงานเพิ่ม ไม่ใช่การแก้ป้าย)
