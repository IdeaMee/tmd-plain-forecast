# 0019 แยกเอกสารงานร่วมกับผู้ช่วย AI ไปไว้ที่ `ai/` และเหลือเอกสารภาพรวมที่ราก

Status: accepted (2026-11-19, ผู้ใช้สั่งในแชต "จัดโฟลเดอร์ md เลย" หลังคุยแผน) · แก้ส่วนที่เกี่ยวกับตำแหน่งไฟล์ใน ADR 0008 และ 0009 (ตัวเนื้อ ADR เดิมไม่แก้ พาธในนั้นคือตำแหน่งก่อนวันนี้)

Context: รากของ repo มี md 7 ไฟล์ปนกัน ทั้งเอกสารภาพรวม (`README.md`, `PLAN.md`, `THIRD_PARTY_NOTICES.md`) มาตรฐานดีไซน์ (`DESIGN-expo.md`) และไฟล์ที่ใช้สั่ง/ติดตามงานของผู้ช่วย AI (`CLAUDE.md`, `AGENTS.md`, `PROGRESS.md`) และมี `plans/` (แผน phase 15 ไฟล์) กับ `docs/archive/` และ `docs/research/R1-R4` ที่เป็นเอกสารกระบวนการทำงานปนกับเอกสารของโปรเจกต์ ผู้ที่เปิด repo ครั้งแรกหาภาพรวมและขอบเขตงานได้ยาก

Decision:
- **รากเหลือเอกสารภาพรวม:** `README.md` (ภาพรวม ติดตั้ง ใช้งาน), `PLAN.md` (โจทย์ ไอเดีย ขอบเขต สถาปัตยกรรม ข้อมูล ความเสี่ยง ตัดส่วนขั้นตอนทำงานกับ AI ออก เลขหัวข้อคงเดิม), `THIRD_PARTY_NOTICES.md` และ `AGENTS.md` (อยู่ที่รากเพราะ `next dev` สร้างและเขียนกลับให้ที่นั่น)
- **`ai/`:** `README.md` (ดัชนี ลำดับงาน 3 ขั้น กฎสำหรับผู้ช่วย) · `PROGRESS.md` · `plans/` (จากรากเดิม) · `archive/` (จาก `docs/archive/`) · `research/` (เฉพาะ R1-R4 จาก `docs/research/`; ไฟล์ค้นคว้าข้อมูล TMD ยังอยู่ที่ `docs/research/`)
- **`.claude/CLAUDE.md`:** ย้ายจากราก ตำแหน่งนี้ Claude Code รองรับโดยตรงตามเอกสาร ("A project CLAUDE.md can be stored in either `./CLAUDE.md` or `./.claude/CLAUDE.md`") นำเข้า `AGENTS.md` ด้วย `@../AGENTS.md` เพราะพาธ @import คิดจากตำแหน่งของไฟล์ที่เขียน
- **`docs/design/DESIGN-expo.md`:** ย้ายจากราก เพราะเป็นเอกสารอ้างอิงด้านดีไซน์ ไม่ใช่คำสั่งสำหรับผู้ช่วย (ยังอ่านอย่างเดียว ห้ามแก้เนื้อหา)
- ลิงก์ markdown ทั้ง 132 ไฟล์ถูกปรับด้วยสคริปต์ และพาธที่เขียนเป็นข้อความถูกแก้ในเอกสารที่ยังใช้งานอยู่ (กฎ/skill, README, PLAN, spec, แผน phase, PROGRESS) ส่วนเอกสารประวัติ (`ai/archive/`, `ai/research/`, ADR 0001-0018) คงข้อความเดิม · `eslint.config.mjs` และ `vercel.json` ตัดโฟลเดอร์ `ai/` ออกจากการตรวจ/แพ็กเกจ

Consequences: เปิด repo แล้วเห็นภาพรวมงานที่ราก ส่วนวิธีทำงานกับผู้ช่วยและบันทึกความคืบหน้าอยู่ใน `ai/` เมื่อเริ่ม session ผู้ช่วยต้องโหลด `.claude/CLAUDE.md` ได้ (ตรวจด้วย `/context`) ถ้าไม่โหลดให้คืนไฟล์สั้นที่รากแทน ADR 0008/0009 ที่เขียนว่า `CLAUDE.md`/`PROGRESS.md`/`plans/` อยู่ที่รากให้ถือว่าเป็นตำแหน่งก่อน 2026-11-19 ข้อเท็จจริงเรื่องที่มาของงาน (ผู้ช่วย AI สร้างโค้ดและป้ายข้อมูล ป้ายไม่ผ่านการตรวจโดยคน ADR 0012) ไม่เปลี่ยนและถูกระบุไว้ใน `ai/README.md`
