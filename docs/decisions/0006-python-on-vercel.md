# 0006 Python บน Vercel สำหรับ /demo (มีเงื่อนไขทดสอบก่อน)

Status: accepted โดยมีเงื่อนไข (2026-11-16) · **เงื่อนไขผ่านแล้ว (2026-11-16): spike ผ่านทั้ง 6 ข้อ ใช้แผน A** ดู `docs/results/spike-vercel-python.md`

Context: หน้า /demo ต้องรันท่อประมวลผลตอนมีคนอัปโหลด เอกสาร Vercel: รองรับฟังก์ชันแบบไฟล์ใน `api/` สำหรับโปรเจกต์ที่มีอยู่ และมี "Services" (Beta) สำหรับรัน Python คู่ framework อื่น ข้อจำกัด Hobby: body 4.5 MB, bundle Python 500 MB, 300 วินาที ยังไม่มีการทดสอบ deploy จริง

Decision: ใช้ฟังก์ชัน Python ใน `api/` (แผน A) ต้องผ่าน spike ใน Phase 0 ก่อนสร้างหน้า /demo (รายการ spike ใน `docs/architecture.md` หัวข้อ 4) ทางถอยที่ผู้ช่วยเสนอ: แผน B (Vercel Services) หรือรัน /demo ที่เครื่องตอนพรีเซนต์ (ผู้ใช้ยังไม่ยืนยันทางถอย)

**ทางถอยตกลงแล้ว (2026-11-16, Q2 ใน `plans/README.md`):** ถ้า spike ไม่ผ่าน ลองแผน B (Vercel Services) หนึ่งรอบ ถ้าไม่ผ่านอีก รัน `/demo` บนเครื่องตอนพรีเซนต์ หน้าหลักไม่กระทบ ผู้ช่วยต้องแจ้งผู้ใช้ก่อนเริ่มทางถอย

Consequences: ถ้า spike ไม่ผ่านต้องกลับมาตัดสินใจกับผู้ใช้ ไม่เปลี่ยนสถาปัตยกรรมเอง หน้าหลักไม่ขึ้นกับผลนี้
