# 0001 ไม่ใช้สคริปต์ดึงเว็บ TMD และเก็บข้อมูลเอง

Status: accepted (2026-11-16) · ส่วน "คุมเบราว์เซอร์รอบเดียว" แก้โดย [ADR 0015](0015-browser-collection-v2.md) (2026-11-18): เก็บด้วยเบราว์เซอร์ได้หลายรอบตามกติกาใน 0015 สคริปต์ยิงเว็บยังห้าม

Context: นโยบายเว็บ TMD ข้อ 3.3 ห้ามใช้วิธีอัตโนมัติ (สคริปต์) นอกช่องทางที่กรมจัดไว้ เว้นแต่ได้รับอนุญาตโดยชัดแจ้ง; `robots.txt` มี `ai-train=no`; CKAN ของ TMD ขอให้ `/api/` ห่างกัน 10 วินาที (ผู้ทำโปรเจกต์เรียกถี่กว่าเล็กน้อยก่อนเห็นไฟล์ แล้วหยุด) โปรเจกต์เป็นงานรายวิชา ไม่ใช้เชิงพาณิชย์ ให้เครดิตกรม

Decision: ผู้ใช้ตัดสินใจให้ไม่ทำอัตโนมัติ: ข้อมูลทั้งหมดโหลดมือหรือผ่านการคุมเบราว์เซอร์ของผู้ช่วยรอบเดียว (ผู้ใช้อนุญาต และรับทราบว่าข้อ 3.3 ต้องการการอนุญาตจากกรม) เก็บในเครื่อง ไม่ใช้ API ข้อมูลที่ดึงด้วยสคริปต์ในรอบสำรวจถูกตัดออก ท่อประมวลผลอ่านไฟล์ในเครื่องเท่านั้น

Consequences: ไม่มีงานตั้งเวลา; อัปเดตข้อมูลวันถัดไปโดยทีมวางไฟล์เอง; ข้อมูลดิบไม่ขึ้น repo; ต้องให้เครดิต "กรมอุตุนิยมวิทยา" ทุกหน้าที่แสดงผล
