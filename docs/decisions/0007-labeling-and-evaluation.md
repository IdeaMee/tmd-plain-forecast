# 0007 วิธีติดป้ายและการวัดผล

Status: accepted (2026-11-16) · ส่วน "ผู้ใช้ติดซ้ำ 20%" ถูกแทนด้วย [0012](0012-agent-labels-without-human-review.md) (2026-11-17)

Context: ข้อมูลที่ติดป้ายได้มีราว 310 หน่วยไม่ซ้ำ (นับหยาบ) เพราะถ้อยคำซ้ำกันมาก ผู้ใช้สั่งให้การวัดผลเป็นขั้นต่ำ ("ทำให้ใช้งานได้ก็พอ") ผู้ช่วยเป็นผู้เขียนคู่มือป้ายเอง

Decision
- ผู้ช่วยติดป้ายทุกหน่วย (4 ป้าย + scope ของ advice) ผู้ใช้ติดซ้ำ 20% (~60 หน่วย) แบบไม่เห็นป้ายผู้ช่วยก่อน เกณฑ์ตรงกัน ≥ 0.8 ผู้ใช้ตัดสินหน่วยที่ไม่ตรง ป้ายสุดท้ายคือป้ายผู้ช่วยที่ผู้ใช้แก้แล้ว รายงานต้องเขียนว่า "ติดโดยโมเดลภาษา ตรวจโดยคน 20%"
- บรรทัดในบล็อกภาคเป็น weather ตามตำแหน่ง ไม่ติดป้ายด้วยมือ
- แบ่งชุดตามวัน; หน่วยถ้อยคำเดียวกันอยู่ชุดเดียวกัน; รายงานผล 2 แบบ (ทุกหน่วย / ถ้อยคำใหม่)
- วัดผลขั้นต่ำ: accuracy ของ Naive Bayes, k-NN, กฎ keyword + ตัวอย่างผิด + ตรวจอัตโนมัติ F1-F7 ไม่ทำ P/R/F1 แยก, ROUGE/BLEU, แบบสอบถาม

Consequences: ความเข้าใจที่ผิดของผู้ช่วยอาจซ้ำทุกแถว (จุดตรวจหลักคือการติดป้ายของผู้ใช้โดยไม่เห็นป้ายก่อน); ความตรงกัน 60 หน่วยไม่พิสูจน์อีกราว 250 หน่วย; เสี่ยงคะแนน Results ถ้าตัดผลวัดมากกว่านี้ รายละเอียด: `docs/spec/labeling-guideline.md`
