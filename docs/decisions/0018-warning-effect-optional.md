# 0018 ช่วงที่มีผลของประกาศเตือนภัยเป็นค่าว่างได้ และชุดประกาศไม่เก็บในสัญญา (แก้สัญญา v2 ของ ADR 0017)

Status: accepted (2026-11-18, ผู้ใช้ยืนยันในแชต "ยืนยัน เซ็นปิด" ตอนเซ็นปิด Phase 11.2) · แก้หัวข้อ v2.3 ของ `docs/spec/data-contract.md`

Context: สัญญา v2 (ADR 0017) กำหนด `WarningNotice.effect` เป็นค่าบังคับ ตอนทำท่อประมวลผลจริงใน 11.2 พบว่าประกาศ 1 ใน 155 ฉบับที่เก็บ (`2569_234` ฉบับที่ 18 ฉบับสุดท้ายของเหตุการณ์) ไม่มีบรรทัด "(มีผลกระทบ...)" เลย ถ้าบังคับต้องเดาช่วงเวลา (ขัดกฎความถูกต้อง) หรือทิ้งฉบับนั้น · แผน 11.2 ให้ "เชื่อมฉบับต่อเนื่อง" ด้วย แต่สัญญาไม่มีฟิลด์ชุดประกาศ

Decision:
- `WarningNotice.effect: EffectPeriod | None` (ไม่มีบรรทัดในต้นฉบับ = `null`) ทั้ง Pydantic และ Zod · ฟิลด์อื่นไม่เปลี่ยน
- การเชื่อมชุดประกาศ (`tmd_plain.doctypes.warning.series.link_series`) เป็นกฎที่คำนวณจากรายการประกาศ (ฉบับที่ n ต่อจาก n-1 ภายใน 48 ชม. หลายชุดพร้อมกันเลือกชุดที่บอกเวลาฉบับต่อไปตรง) ไม่เก็บเป็นฟิลด์ในสัญญา ถ้าหน้า `/warnings` (11.4) ต้องใช้ ให้คำนวณจากรายการหรือเพิ่มฟิลด์ด้วย ADR ภาคต่อ

Consequences: หน้าเว็บที่แสดงประกาศต้องรองรับ `effect` เป็น null (แสดง "ไม่ระบุช่วงที่มีผลในประกาศ") · เทสต์สัญญาเดิมยังผ่าน (ไฟล์ตัวอย่างมี `effect`) · ผลจริง: ทั้ง 155 ฉบับผ่านท่อประมวลผลและตัวตรวจ (`docs/results/warning-check.md`)
