# 0010 มาตรฐานดีไซน์ (DESIGN-expo.md) และฟอนต์ Anuphan

Status: accepted (2026-11-16) · แทนที่ส่วนฟอนต์/มาตรฐาน responsive เดิมใน 0004 และ `frontend-responsive-ui` (Noto Sans Thai, ตัวเลขชุดของเราเอง)

Context
- ผู้ใช้สั่ง: (1) ใช้ฟอนต์ไทย Anuphan (https://github.com/cadsondemak/Anuphan); (2) ให้ `DESIGN-expo.md` ที่ผู้ใช้ใส่ไว้ที่ Root เป็น **มาตรฐานดีไซน์หลัก** อ่านอย่างเดียว ไม่ต้องแก้ และให้เอกสารอื่นเข้าใจตรงกัน
- DESIGN-expo.md เป็นระบบดีไซน์ที่วิเคราะห์จากเว็บการตลาดของ Expo ใช้ Inter ภาษาอังกฤษ จึงมีค่าที่เหมาะกับละตินอย่างเดียว (letter-spacing ติดลบ ตัวพิมพ์ใหญ่เว้นอักษร line-height 1.05-1.5) และคอมโพเนนต์การตลาดที่แอปเราไม่ต้องใช้
- ตรวจ Anuphan (2026-11-16): ใบอนุญาต OFL-1.1, ฟอนต์ตัวแปรน้ำหนัก 100-700, มีชุดอักษรไทย, ใช้ผ่าน `next/font/google` ได้ (อยู่ในรายการของ Next.js 16.4.6)
- คำนวณความต่างสีของโทเคนในมาตรฐานเองพบว่าบางคู่ไม่ถึง 4.5:1 (เช่น `muted`, `semantic-error`) ดู `docs/spec/design-system.md` หัวข้อ 6

Decision
- DESIGN-expo.md คือมาตรฐานหลัก: ทุกค่าตามมาตรฐาน ยกเว้นข้อที่ลงตาราง D1-D10 ใน `docs/spec/design-system.md` (แต่ละข้อมีเหตุผลและวิธีย้อนกลับ) ห้ามแก้ DESIGN-expo.md การเบี่ยงเพิ่มต้องเพิ่มแถวในตารางนั้นหรือเขียน ADR
- ฟอนต์ **Anuphan** ฟอนต์เดียวทุกบทบาท แทน Inter; ไม่โหลด JetBrains Mono
- โทเคนอยู่ที่เดียว: `@theme` ใน `app/globals.css` ใช้ชื่อเหมือนมาตรฐาน คอมโพเนนต์ห้ามใส่ hex/ขนาด/รัศมีเอง
- ไม่สร้างคอมโพเนนต์การตลาดของมาตรฐาน (mockup อุปกรณ์ ราคา ระบบนิเวศ รีวิว)
- ปรับสำหรับภาษาไทย: letter-spacing 0, ไม่ใช้ตัวพิมพ์ใหญ่, line-height หัวข้อ 1.3 เนื้อหา 1.6, พื้นที่กดบนจอสัมผัส 44px, ห้ามใช้ `muted`/`semantic-error`/`semantic-success` เป็นสีข้อความ
- เอกสารที่อ้างมาตรฐานนี้แล้ว: `CLAUDE.md`, `.claude/rules/frontend.md`, skill `frontend-responsive-ui` และ `nextjs-component-architecture`, `planning-phases`, `docs/spec/ui-spec.md`, `docs/spec/design-system.md`, `PLAN.md`

Consequences
- ข้อดี: หน้าตาสม่ำเสมอ มีแหล่งอ้างอิงเดียว; คนที่เขียนหน้าเว็บต่อไม่ต้องเดาค่า
- ความเสี่ยง/ยังไม่ได้ตรวจ: Anuphan เรนเดอร์จริงกับ line-height ที่เลือก (ค่าไทยเป็นหลักปฏิบัติทั่วไป ไม่ใช่ตัวเลขทางการ); ไวยากรณ์ `@theme`/`@source` ของ Tailwind 4 ที่ติดตั้ง; มาตรฐานมีตัวเลขบางข้อที่ไม่ตรงเกณฑ์ WCAG (ปุ่ม 40px, สีข้อความรอง) ซึ่งเราปรับไว้แล้ว; เลย์เอาต์การ์ด 7 ใบที่ 3 คอลัมน์ยังเหลือใบเดียวท้ายแถว
- ใช้ชื่อ "Expo" ของมาตรฐานเฉพาะเป็นชื่อไฟล์อ้างอิง ไม่ใช้โลโก้ ชื่อแบรนด์ หรือรูปของ Expo ในแอป (ดู `THIRD_PARTY_NOTICES.md`)
