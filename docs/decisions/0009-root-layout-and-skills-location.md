# 0009 โครงรากของโปรเจกต์ และที่เก็บ skill/กฎ/แผน

Status: accepted (2026-11-16)

Context
- รอบแรก (ADR 0008) สร้างชุด md/skill ไว้ในโฟลเดอร์ย่อย `tmd-plain-forecast/` ส่วนที่ Root ของโปรเจกต์ปนกัน: เอกสารวางแผน 9 ไฟล์ (PLAN.md ยาว 84 KB, BUILD-PLAN/STATE ที่เลิกใช้แล้ว), ผลค้นคว้า, ข้อมูลดิบ, บันทึกเนื้อหาวิชา และ `docs/` ที่เป็นสไลด์ของอาจารย์ ซึ่งชื่อซ้ำกับ `docs/` ของโปรเจกต์
- ผู้ใช้สั่ง (2026-11-16): ไม่เก็บ skill ไว้ใน `tmd-plain-forecast/` ให้อยู่ที่ Root, วิเคราะห์ปรับโครงโฟลเดอร์และไฟล์ md ที่ Root ให้เป็นมาตรฐาน, และให้ md แผนงานอยู่ที่ Root เพื่ออ่านง่ายตลอด
- `CLAUDE.md` โหลดจากโฟลเดอร์ที่เปิดทำงานและโฟลเดอร์แม่ของมัน ส่วน `.claude/rules/` และ `.claude/skills/` ของโปรเจกต์ผูกกับโฟลเดอร์ที่เปิดทำงาน ถ้าเก็บไว้ในโฟลเดอร์ย่อยแล้วเปิดจากโฟลเดอร์แม่ อาจโหลดไม่ครบ (ยังไม่ได้ทดสอบ)

Decision
- **ตีความ "Root" = โฟลเดอร์ `NLP & ML Mini-Project`** (ไม่ใช่โฟลเดอร์วิชา `1322308 การเรียนรู้ของเครื่อง` ซึ่งมีโปรเจกต์อื่นอยู่ด้วย) โฟลเดอร์นี้เป็นราก repo และราก Vercel project เปิด Claude Code จากที่นี่
- ย้ายทุกอย่างใน `tmd-plain-forecast/` ขึ้นมาที่ราก (`CLAUDE.md`, `.claude/`, `docs/`, `README.md`, `THIRD_PARTY_NOTICES.md`) โฟลเดอร์ย่อยเดิมว่างแล้วถูกลบ (ลบแค่โฟลเดอร์ว่าง ไม่มีไฟล์หาย)
- ที่ราก มีเฉพาะ: `PLAN.md` (แผนหลักฉบับสั้นใหม่), `PROGRESS.md`, `CLAUDE.md`, `README.md`, `DESIGN-expo.md`, `THIRD_PARTY_NOTICES.md`, `.gitignore`, โฟลเดอร์ `.claude/`, `docs/`, `plans/`, `data/`, `course/` (+ โค้ดของแอปในอนาคต) ดูแผนผังที่ `docs/architecture.md` หัวข้อ 2
- `PLAN.md` ฉบับยาวเดิม (ประวัติ + decision log) ย้ายไป `docs/archive/PLAN-history.md` ส่วน BUILD-PLAN, STATE, SETUP-PROPOSAL และร่างคู่มือป้าย/ตารางแมปภาคต้นฉบับย้ายไป `docs/archive/` ผลค้นคว้าและสรุปข้อมูลเว็บ TMD ย้ายไป `docs/research/`
- `plans/` อยู่ที่ราก (แผนแต่ละ phase ของขั้น 2) `PROGRESS.md` อยู่ที่ราก
- ข้อมูล: `dataset-raw/` -> `data/raw/`, `_excluded-scripted-downloads/` -> `data/excluded-scripted/` (ชื่อ `data/raw/` ตรงกับที่ skill และสเปกเขียนไว้แล้ว)
- เนื้อหารายวิชา: `docs/` เดิม (สไลด์) -> `course/slides/`, `notes/` -> `course/notes/` เพื่อให้ `docs/` เป็นเอกสารของโปรเจกต์อย่างเดียว
- ย้ายอย่างเดียว ไม่ลบเนื้อหา ลิงก์ที่คลิกได้ในเอกสารถูกแก้ตาม ตารางย้ายอยู่ที่ `docs/archive/README.md`
- สร้าง `.gitignore` ที่ราก กันข้อมูลดิบ สไลด์ของอาจารย์ และไฟล์ digest ของเว็บ TMD ออกจาก repo (ยังไม่ได้ `git init` เพราะผู้ใช้ไม่ได้สั่ง)

Consequences
- ข้อดี: แผนอ่านง่ายที่ราก; skill/กฎโหลดอัตโนมัติเมื่อเปิดจากราก; `docs/` ไม่ชนชื่อกัน; ราก repo = ราก Vercel ตรงกับสถาปัตยกรรม
- ข้อเสีย/ความเสี่ยง: (1) ราก Vercel/Next.js มีโฟลเดอร์ที่ไม่ใช่แอปปนอยู่ (ต้องตั้ง `@source` ของ Tailwind และ `excludeFiles` ของ Python ใน Phase 0); (2) path ของราก มีภาษาไทย ช่องว่าง และ `&` ซึ่งยังไม่ได้ทดสอบกับ Next.js build และ npm scripts บน Windows (ทางถอยคือให้ผู้ใช้ย้าย/clone ไป path สั้น); (3) `create-next-app` อาจไม่ชอบโฟลเดอร์ไม่ว่าง; (4) ยังไม่ได้ทดสอบว่า Claude Code โหลด skill/กฎจากรากใหม่จริง; (5) session ที่เปิดจากโฟลเดอร์วิชา (แม่) จะไม่เห็น skill เหล่านี้ ให้เปิดจากราก
- **ผู้ใช้ยืนยันแล้ว (2026-11-16):** ราก = `NLP & ML Mini-Project` เป็นโฟลเดอร์ทำงานหลัก แม้ Claude จะเข้าถึงโฟลเดอร์วิชาด้านนอกได้ก็ตาม
- (ข้อสันนิษฐานเดิมก่อนยืนยัน) ถ้าผู้ใช้หมายถึงให้ราก = โฟลเดอร์วิชา (`1322308 การเรียนรู้ของเครื่อง`) ต้องแก้ ADR นี้และย้ายอีกรอบ (โฟลเดอร์นั้นมี `ML_Notes/` ที่มี CLAUDE.md ของตัวเอง จึงเสี่ยงชนกัน)
