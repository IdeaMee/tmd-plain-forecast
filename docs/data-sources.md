# แหล่งข้อมูลและเครดิต

ข้อมูลทั้งหมดเป็นของ **กรมอุตุนิยมวิทยา** (https://www.tmd.go.th) หน้าลิขสิทธิ์ของเว็บอนุญาตให้เผยแพร่ต่อแบบไม่แสวงหากำไร โดยต้องระบุแหล่งที่มา "กรมอุตุนิยมวิทยา" ทุกครั้ง และกรมไม่รับประกันความถูกต้อง โปรเจกต์นี้เป็นงานรายวิชา ไม่ใช้เชิงพาณิชย์

- พยากรณ์ 7 วัน: `/forecast/sevenday` 19 ฉบับ (PDF; ฉบับล่าสุดมีข้อความด้วย) 28 ต.ค.-16 พ.ย. 2026 (ฉบับ 31 ต.ค. ไม่มี)
- รวม 112 ไฟล์ เก็บในเครื่อง (`data/raw/`) ไม่ขึ้น repo; มี `MANIFEST.csv` ระบุที่มา ขนาด sha256 และบทบาท (แสดง/ทดสอบ หรือฝึก)

## วิธีเก็บ
- รอบแรก (2026-11-16): คุมเบราว์เซอร์ (Claude in Chrome) รอบเดียว เปิดทีละหน้า เว้นจังหวะ ผู้ใช้อนุญาตและรับทราบข้อกำหนดของเว็บ ไม่ใช้ API หรือสคริปต์ดึงข้อมูล
- รอบ v2 (ตั้งแต่ 2026-11-18): ผู้ใช้อนุมัติในแชตให้เก็บหลายรอบด้วยเบราว์เซอร์ ([ADR 0015](decisions/0015-browser-collection-v2.md), ผู้ใช้อนุมัติ 2026-11-18) วิธีละเอียด: [research/collection-procedure.md](research/collection-procedure.md)

## ข้อกำหนดที่ต้องจำ
- นโยบายเว็บ TMD ข้อ 3.3: ห้ามสคริปต์อัตโนมัตินอกช่องทางที่กรมจัดไว้ เว้นแต่ได้รับอนุญาต -> ระบบนี้ไม่ดึงเว็บ TMD อัตโนมัติ
- `robots.txt` ของ TMD มี `Content-Signal: ai-train=no` ผู้ใช้รับทราบว่าเป็นงานรายวิชา ไม่ใช้เชิงพาณิชย์
- อย่านำข้อมูลดิบขึ้น repo สาธารณะ

## ข้อควรระวังด้านคุณภาพ
