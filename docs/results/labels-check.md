## กรณีก้ำกึ่งที่พบบ่อย
- **หน่วยกลไก + สภาพอากาศ/คลื่นในประโยคเดียว** (ฉบับ 7 วัน คู่มือไม่ให้ตัดที่ "สำหรับ"): ติด `cause` ตามส่วนแรก พร้อม note
- **คลื่นลม + คำแนะนำชาวเรือในหน่วยเดียว:** ติด `advice` (มีคำแนะนำมาก่อน)
- **"ช่วงเวลาดังกล่าว" / "บริเวณดังกล่าว":** รับพื้นที่จากหน่วยก่อนหน้า (D5) ถ้าไม่แน่ใจรวมกว้างไว้ (D7)
- **ชาวเรือ / เรือเล็ก:** อ่าวไทย = E SE, อ่าวไทยตอนล่าง = SE, อันดามัน = SW, ชาวเรือไม่ระบุทะเล = E SE SW
