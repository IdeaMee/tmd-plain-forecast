## ข้อมูล
- ฝึก 118 หน่วย (weather 49, advice 21, cause 47, other 1) · dev 28 · ทดสอบ (ก) ทุกหน่วยที่ปรากฏในวันทดสอบ 128 หน่วย (317 ครั้งที่ปรากฏ) · (ข) เฉพาะถ้อยคำใหม่ 120 หน่วย
- คุณลักษณะ: bag of words (นับความถี่) บนผลตัดคำ newmm + พจนานุกรมคำอากาศ ตัวเลขรวมเป็นโทเคน `<num>` · Vocabulary ชุดฝึก 203 คำ
- Naive Bayes: P(w|c) = (n_k + m·p)/(n + m), p = 1/|Vocabulary|, log probability (สไลด์ ML 08)
- k-NN: ระยะ L2 บนเวกเตอร์ความถี่ที่ปรับให้ยาว 1, โหวตเสียงข้างมาก (บันทึก ML 04)
- กฎ keyword: เขียนใน Phase 2.1 ก่อนมีป้าย ไม่ได้ฝึกและไม่ได้ปรับ

## ข้อจำกัด
- ป้ายไม่ได้ผ่านคนตรวจ (ADR 0012) ความผิดของผู้ช่วยตอนติดป้ายจะไม่ปรากฏเป็นความผิดของโมเดล
- `other` มีหน่วยเดียวในข้อมูลทั้งหมด (อยู่ชุดฝึก) โมเดลจึงแทบทายป้ายนี้ไม่ได้ และชุดทดสอบไม่มีป้ายนี้
- ชุดฝึก 118 หน่วยและ dev 28 หน่วยเล็ก ตัวเลขแกว่งได้มากถ้าเปลี่ยนวันแบ่งชุด · TMD ใช้ถ้อยคำซ้ำเป็นแบบแผน accuracy จึงสูงได้ง่าย
- กฎ keyword ได้ accuracy สูงกว่าโมเดลที่เรียน ส่วนหนึ่งเพราะป้ายของผู้ช่วยตรงกับกฎ 288/292 หน่วยตั้งแต่ก่อนวัดผล (ผู้ติดป้ายกับกฎใช้เกณฑ์คล้ายกัน และ TMD ใช้ถ้อยคำเป็นแบบแผน) จึงไม่ได้แปลว่ากฎจะดีกว่ากับถ้อยคำแบบอื่น · โมเดลที่เรียนยังจำเป็นตามข้อกำหนดรายวิชา และใช้ตรวจหน่วยที่กฎกับโมเดลเห็นต่างกันได้
- ไม่ได้วัด precision/recall/F1 แยกป้าย (ADR 0007 ตกลงวัดขั้นต่ำเป็น accuracy + ตัวอย่างผิด)
