## 3. ข้อมูลข้อความบรรยายที่มี แบ่งตามประเภท

### 3.1 ประกาศเตือนภัย (หลักของ "ภาษาสั้น")
- **feed `storm-tracking`:** 1,491 ฉบับ ข้อความกลาง 207 อักษร คำไม่ซ้ำราว 750 คำ ฉบับต่อเนื่องคล้ายกันมัธยฐาน 0.91 และ 22% ซ้ำทุกตัวอักษร (168 ชุดเลขฉบับ ราว 142 เหตุการณ์ 92 หัวข้อที่ normalize แล้ว ตามเอเจนต์ D) ประโยค "ขอให้…" มีแค่ 9.7% ความผิดปกติ: ปีพิมพ์ผิด 1 ฉบับ ข้อความว่าง 3 ฉบับ เลขประกาศซ้ำ 3 ฉบับ ตารางแยกแล้วที่ `data-samples/derived/D-bulletins.jsonl`
- **หน้าเว็บ `/warning-and-events/warning-storm`:** ลิสต์เป็นหน้าต่าง 3 เดือน 155 ฉบับ (เลขที่ 157-311/2569, 16 ส.ค.-16 พ.ย. 2569) หน้ารายละเอียดมีข้อความประกาศเต็มและสาเหตุ (feed ไม่มี) และ 154 ฉบับมี PDF แนบที่มีตารางจังหวัดรายวัน (ไม่อยู่ใน HTML) PDF เหล่านี้ pdftotext อ่านไทยไม่ได้ ต้องใช้ PyMuPDF เอเจนต์ C อ่านเนื้อ PDF แค่ 17 ฉบับ
- ไฟล์ประกาศเก่ากว่า 16 ส.ค. หาได้บางส่วนด้วยรูปแบบ `YYYY-MM_DD_05|17_warning_th.pdf` (ตามเอเจนต์ E)

## 4. คุณภาพข้อความภาษาไทยจาก PDF (วัดแล้ว)

- ทุกไฟล์ที่ดูมีชั้นข้อความ แต่ **ความเสียหายต่างกันตามฉบับ**: "ำ"→"า" หรือ "้า", วรรณยุกต์หาย, "°" กลายเป็น "ํ" (49 ตัวในไฟล์รายฤดู ตรวจแล้ว), "เอลนีโญ"→"เอญนีโญ", "70-90"→"7090" (1 จุด), ปี ≤2566 "ำ" หาย และบางไฟล์ใช้อักขระ PUA (U+F70A-F70E) แทนวรรณยุกต์ (E)
- **ตารางในชั้นข้อความส่วนใหญ่ลำดับสลับ** ต้องสร้างใหม่จากภาพหน้า (ยกเว้นตารางสถานี 72 แห่งของสรุปรายเดือน)
- **pdftotext ล้มเหลวกับบางไฟล์** (PDF ประกาศแนบ คู่มือ API) ต้องใช้ PyMuPDF
- PDF เก่าบางกลุ่มเป็นภาพล้วน (สรุปรายสัปดาห์ก่อน ส.ค. 2568, สถิติพายุ 72 ปี)
- metadata ของ PDF ไม่น่าเชื่อ (ชื่อเรื่องค้างเป็น "มีนาคม 2568", "ฤดูร้อน 2541")

## 5. ภาษาอังกฤษ
