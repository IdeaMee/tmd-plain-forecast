# แผนผังเว็บ tmd.go.th (ข้อมูลดิบตั้งต้น)

เว็บกรมอุตุนิยมวิทยา https://www.tmd.go.th/ สำรวจเมื่อ 14 พ.ย. 2026 (2569) ไฟล์นี้บันทึกเฉพาะ **ว่าเว็บมีหน้าอะไร แต่ละหน้ามีข้อมูลแบบไหน และหน้าไหนมี PDF/ไฟล์ให้ดาวน์โหลด** ยังไม่มีเรื่องแผนโปรเจกต์ และยังไม่ได้เปิดอ่านเนื้อหาใน PDF

## 1. วิธีสำรวจและขอบเขต

- ดึงลิงก์ทั้งหมดจากเมนูหน้าแรกได้ 151 ลิงก์ที่ไม่ซ้ำ
- **หน้าในโดเมน www.tmd.go.th:** เปิดโหลดในเบราว์เซอร์ + ดึง HTML ตรวจ ประมาณ 65 หน้า (ดูตารางข้างล่าง)
- **หน้านอกโดเมน (โดเมนย่อยของ tmd.go.th):** ตรวจแค่สถานะ HTTP + ชื่อหน้า ไม่ได้ดูเนื้อหา
- เว็บหลักเป็น HTML ที่เซิร์ฟเวอร์สร้างให้ (CMS: Orchard Core) อยู่หลัง Cloudflare ดึงข้อความจาก HTML ตรงๆ ได้ ไม่ต้องรอ JavaScript ส่วนใหญ่
- ประเภทข้อมูลที่ใช้ในตาราง: **ข้อความ** = เนื้อหาบรรยายเป็นภาษาไทย, **ตัวเลข** = ตาราง/ค่าสังเกต, **ภาพ** = กราฟิก/แผนที่เป็นรูป, **PDF** = มีไฟล์ให้ดาวน์โหลด
