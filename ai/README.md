# ai/ — งานที่ทำกับผู้ช่วย AI

โฟลเดอร์นี้รวมทุกอย่างที่เกี่ยวกับ **วิธีสร้างโปรเจกต์นี้ร่วมกับผู้ช่วย AI** (Claude Code): ลำดับงาน แผนแต่ละ phase บันทึกความคืบหน้าและจุดส่งต่อ งานค้นคว้าที่ใช้ตั้งกฎ และเอกสารร่างเก่า ส่วนภาพรวม ขอบเขต และสถาปัตยกรรมของโปรเจกต์อยู่ที่ [README.md](../README.md) และ [PLAN.md](../PLAN.md) ที่ราก

ข้อเท็จจริงเรื่องที่มาของงาน (บันทึกไว้ตรงๆ): โค้ด ท่อประมวลผล เอกสาร และ **ป้ายข้อมูล (label) สร้างโดยผู้ช่วย AI ภายใต้การสั่งและการรีวิวของผู้ใช้** ป้ายข้อมูลยังไม่ผ่านการตรวจโดยคน (ดู [ADR 0012](../docs/decisions/0012-agent-labels-without-human-review.md)) ตัวเลขความแม่นของโมเดลจึงวัดเทียบกับป้ายชุดนี้

| ไฟล์/โฟลเดอร์ | มีอะไร |
|---|---|
| [PROGRESS.md](PROGRESS.md) | ความคืบหน้าทุก phase, จุดส่งต่อ (handoff) ที่ต้องอ่านก่อนทำต่อ, ผลคำสั่งตรวจจริง |
| [plans/](plans/README.md) | แผนละเอียดแต่ละ phase (00-13) ของขั้น 3 และรอบปรับปรุง v2 |
| [archive/](archive/README.md) | ร่างเก่าที่ถูกแทนที่ และ `PLAN-history.md` (decision log ฉบับเต็ม) |
| [research/](research/) | งานค้นคว้า R1-R4 (skill และ CLAUDE.md, โครงโฟลเดอร์, เทคโนโลยีและมาตรฐาน UI, แนวปฏิบัติด้านวิศวกรรม) |
| [../.claude/CLAUDE.md](../.claude/CLAUDE.md) | กฎประจำโปรเจกต์ที่ผู้ช่วยโหลดทุกครั้งที่เริ่ม session |
| [../.claude/rules/](../.claude/rules/), [../.claude/skills/](../.claude/skills/) | กฎตามชนิดไฟล์ และขั้นตอนงาน (skill) |

## ลำดับงาน 3 ขั้น (ผู้ใช้กำหนด)
ย้ายมาจาก [PLAN.md](../PLAN.md) หัวข้อ 1 (ปรับลิงก์ให้ชี้จากโฟลเดอร์นี้)

| ขั้น | ทำอะไร | สถานะ |
|---|---|---|
| 1 | เตรียมแผน ข้อมูล คู่มือป้าย เอกสาร (md) และ skill | **ครบ** |
| 2 | วิเคราะห์และแบ่ง phase ด้วย skill `planning-phases` ผลอยู่ที่ [plans/](plans/) (7 แผน 24 phase, Q1-Q5 ใช้ค่าเริ่มต้น) | **ครบ (ผู้ใช้ยอมรับ 2026-11-16)** |
| 3 | เจนโค้ดทีละ phase (ผู้ใช้เปลี่ยนไปใช้ Fable/Opus) รวมการติดป้ายข้อมูล (ต้องมีโค้ดตัดหน่วยก่อน) | **ครบตามแผนเร็ว** (Phase 0-5, 6.1, ชุด A-C เสร็จและขึ้นเว็บ ดู [PROGRESS.md](PROGRESS.md)) |
| 3+ | รอบปรับปรุง v2 (ผู้ใช้ขอ 2026-11-18): หมวดใหม่ 5 หมวดใหญ่ (เดินเรือ, ประกาศเตือนภัย `/warnings`, สรุปรายสัปดาห์ `/summaries`; รอบ 2 `/agro`, `/outlooks`), `/demo` 3 ระดับ + ภาพขั้นตอนอัลกอริทึม, หน้า `/model`, ดีไซน์ใหม่ + อนิเมชัน, เก็บข้อมูลย้อนหลังด้วย Claude in Chrome · แผน [07-13](plans/README.md) 23 phase แล้วจึง 6.2 | **เสร็จเกือบหมด** (แผน 12 และ 9.3 ทำต่อเมื่อผู้ใช้สั่ง) |
