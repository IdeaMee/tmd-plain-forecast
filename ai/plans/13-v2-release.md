## Phase 13.1: ตรวจทั้งระบบ + smoke ขยาย + code review + deploy   [M]   [เจ้าของ: ผู้ช่วย; ผู้ใช้ push/ลองมือถือ]

Goal: รอบ v2 พร้อมส่ง: ทุกเทสต์ผ่าน, ไม่มี finding ค้าง, เว็บจริงทำงานครบทุกหน้า

Tasks
1. รันทุกคำสั่งตรวจใน `.claude/CLAUDE.md` Commands จากสถานะสะอาด (ลบ `.next` ก่อน build) รวม `check_*` ทุกตัว, `freeze_labels.py`, `train_eval.py` + `train_eval_warning.py` (sha256 โมเดลเท่าเดิม), `export_model_report.py` (ไม่เก่า), `measure_trace.py` · บันทึกผลจริงใน `ai/PROGRESS.md`
2. `/code-review` ระดับ high บนการเปลี่ยนแปลงตั้งแต่ `be6f44e` (ส่วนที่ชุด A/B ยังไม่ได้ review high) → แก้ finding → รันตรวจซ้ำ
3. `tests/smoke/live.spec.ts`: เพิ่มข้อที่ยังไม่ครอบ: แท็บเดินเรือ, `/summaries`, ตัวเลือกรอบตามเดือน (เปิดเดือนเก่าสุด), `/demo` ผลเดินเรือ/ประกาศ/รายสัปดาห์ (อัปโหลดจริงถ้ามี PDF), `/model/warning`, เมนูมือถือ, reduced-motion → `docs/results/smoke-test.md`
4. ขนาดและเวลา: bundle ฟังก์ชัน Python (< 500 MB จากหน้า Resources ที่ผู้ใช้เปิดให้ดู), เวลาตอบ `/demo` บน PDF ใหญ่สุดในชุด, ขนาดฐานจริง
5. เอกสารให้ตรงของจริง: `PLAN.md`, `.claude/CLAUDE.md` (หน้า, ชนิดเอกสาร, คำสั่ง), `docs/README.md`, `docs/spec/*`, `docs/data-sources.md`, `ai/plans/README.md` (สถานะ)

Checks
- pytest, ruff, typecheck, lint, `npm test`, build, `npm run e2e` ผ่านทั้งหมด (ตัวเลขจริงในรายงาน) · `check_*` ทุกตัว errors 0 · finding ระดับ correctness ค้าง 0
- หลังผู้ใช้ push: `npm run smoke` ผ่านทั้งหมด

Human steps
- ผู้ใช้สั่ง commit + `git push all main` · ผู้ใช้ลองเว็บจริงบนมือถือ (เมนู การ์ดภาค เดินเรือ ประกาศ รายสัปดาห์ `/model` `/demo`)

Stop conditions
- เทสต์ใดล้มสองรอบหลังแก้ → หยุดถามผู้ใช้

## Phase 13.2: README ผลวัด และสรุปสำหรับสไลด์ (เดิม 6.2 ส่วนผู้ช่วย)   [S]   [เจ้าของ: ผู้ช่วย; ผู้ใช้ให้ข้อมูลสมาชิก]
