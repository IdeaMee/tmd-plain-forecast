# tmd-plain-forecast

ระบบสรุปพยากรณ์อากาศของกรมอุตุนิยมวิทยา (รายวัน และ 7 วัน) เป็นภาษาไทยง่ายๆ แยกตามภาค ใช้วิธีที่เรียนในวิชา Natural Language Processing (NLP) และ Machine Learning (ML) งานกลุ่มรายวิชา ไม่ใช้เชิงพาณิชย์

> สถานะ: **ขั้นเตรียมแผน** ยังไม่มีโค้ด ไฟล์นี้เป็นโครง README ตามเกณฑ์วิชา ต้องเติมเมื่อมีโค้ดจริง (วิธีรัน ผลลัพธ์ ลิงก์เว็บ)

## 1. ไอเดีย
- **ปัญหา:** ข้อความพยากรณ์ของ TMD เขียนครอบคลุมทั้งประเทศและปนสาเหตุเชิงเทคนิคกับคำเตือน ประชาชนต้องหาเองว่าภาคตัวเองเป็นอย่างไร
- **ผู้ใช้:** ประชาชนทั่วไป
- **สิ่งที่ทำ:** เว็บแสดงสรุปภาษาง่ายครบ 7 ภาค ย้อนหลัง 1 สัปดาห์ และหน้า `/demo` ให้อัปโหลด PDF พยากรณ์เพื่อลองใช้
- **วิธี:** ท่อประมวลผล 4 ขั้น (เตรียมข้อความ, จัดประเภทประโยคด้วย Naive Bayes เทียบ k-NN, ดึงข้อมูล, เขียนประโยคด้วยแม่แบบ) รายละเอียด: [docs/spec/scope-and-pipeline.md](docs/spec/scope-and-pipeline.md)
- **ข้อจำกัด:** ใช้ได้กับพยากรณ์รายวัน/7 วันของ TMD เท่านั้น ผลวัดมาจากข้อมูลปลายตุลาคม-กลางพฤศจิกายน 2026 ไม่ใช่ประกาศทางการ
