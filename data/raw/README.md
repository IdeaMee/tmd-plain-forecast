## วิธีเก็บ
- เก็บผ่าน Claude in Chrome (Chrome ของผู้ใช้) เปิดทีละหน้า เว้นจังหวะประมาณ 8 วินาทีต่อรอบ รอบเดียว ไม่ใช้ API ไม่ตั้งเวลาโหลดซ้ำ
- ข้อความ: ข้อความที่เบราว์เซอร์แสดง (innerText) ของเนื้อหาหลักในหน้า HTML เก็บเป็น `.txt` มีหัวไฟล์ `# source / round_id / label / pdf / saved_at` นำหน้า
- PDF: ไฟล์ที่เว็บให้ดาวน์โหลดตามปุ่ม "ดาวน์โหลดเอกสาร" (พยากรณ์ 7 วันฉบับเก่าเปิดตามรูปแบบชื่อไฟล์ `t_YYMMDD.pdf`)
- ไฟล์ตรวจแล้วด้วย `MANIFEST.csv` (ขนาด + sha256 + ที่มา): PDF ขึ้นต้นด้วย `%PDF-` ทุกไฟล์; ข้อความรายวันมีบล็อกภาคเหนือ/กลาง/กรุงเทพฯ ครบทุกไฟล์; ข้อความ 7 วันมี "ภาคเหนือ / ภาคกลาง / ข้อควรระวัง"
